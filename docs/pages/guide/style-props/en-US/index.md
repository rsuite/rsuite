# Style Props

React Suite provides a series of style property shorthands for more concise style settings. These properties directly map to their corresponding CSS properties.

## Usage

### Theme Values

Provided theme presets, for example:

```jsx
<Box bg='blue.600' />
<Box rounded='lg' />
```

### Responsive Values

Provided responsive values, for example:

```jsx
<Box w={{ xs: '100%', md: '80%', lg: '60%' }} />
<Box p={{ xs: '10px', md: '20px' }} />
```

## Server-rendered styles

Use `StyleRegistry` to include CSS generated by style props in the server HTML, before JavaScript loads. Create a new registry for every server request and use the same component tree on the server and when hydrating.

Put your component in `app.tsx`.

```tsx
import React from 'react';
import { Box } from 'rsuite';

export default function App() {
  return (
    <Box c="#123456" p={{ xs: '8px', md: '16px' }}>
      Responsive content
    </Box>
  );
}
```

In the server entry, render the app before reading the registry. Insert the collected style element into the document head. Serve the browser entry below as `/client.js` using your build tool.

```tsx
import React from 'react';
import { renderToStaticMarkup, renderToString } from 'react-dom/server';
import { StyleRegistry, createStyleRegistry } from 'rsuite';
import App from './app';

export function renderPage() {
  const registry = createStyleRegistry();
  const markup = renderToString(
    <StyleRegistry registry={registry}>
      <App />
    </StyleRegistry>
  );
  const collected = registry.getStyleElement();
  const styles = collected ? renderToStaticMarkup(collected) : '';

  return `<!doctype html>
<html lang="en">
  <head><meta name="viewport" content="width=device-width, initial-scale=1">${styles}</head>
  <body>
    <div id="root">${markup}</div>
    <script type="module" src="/client.js"></script>
  </body>
</html>`;
}
```

In the browser entry (`client.tsx`), keep one registry for the lifetime of the hydrated root. It adopts the rules emitted by the server.

```tsx
import React from 'react';
import { hydrateRoot } from 'react-dom/client';
import { StyleRegistry, createStyleRegistry } from 'rsuite';
import App from './app';

const registry = createStyleRegistry();
const root = document.getElementById('root');

if (root) {
  hydrateRoot(
    root,
    <StyleRegistry registry={registry}>
      <App />
    </StyleRegistry>
  );
}
```

Include the React Suite stylesheet as usual for component styles and theme tokens. For streaming SSR, use your framework’s style insertion hook to emit `registry.getStyleElement()` before the corresponding content, then call `registry.flush()` after inserting each batch. With a Content Security Policy, pass the request’s nonce to `CustomProvider` through `csp={{ nonce }}` on the server and during hydration.
